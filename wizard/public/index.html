Claude server setup

Builds a LAN server from one of your singleplayer worlds, with Claude as a player. You only do this once.

    1. Check

    The server needs Java, the bot needs Node.js, and Claude needs Claude Code to sign in.

    • Checking...

    2. World

    Pick the world to use. It gets copied, never moved, so your singleplayer world stays as it is.

    3. Version

    Everyone who joins must use this Minecraft version. Only versions both Paper and the bot support are listed.

    Upgrading only goes one way: after this, the server copy of the world can't go back to the old version. Your original world isn't touched.

    4. Server

    The server runs in offline mode with SkinsRestorer, so Claude gets its orange skin and everyone else keeps theirs.

    Offline mode means anyone on your Wi-Fi could join with an op's name. That's the accepted trade-off for a LAN-only server.

    5. EULA

    Mojang requires a person to accept the Minecraft End User License Agreement before running a server. Read it at aka.ms/MinecraftEULA.

      • 
        
    • memory.md: Claude's private memory, empty for now
      • 
      
    
      
    Claude's permissions are built into the bot: game actions, its memory, and reading the server folder (writing only in op mode). It can't touch the rest of the PC, even if someone in chat tries to make it.
